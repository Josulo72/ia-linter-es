# MarkdownWiki

Convierte tus apuntes en Markdown a una web estática lista para servir. Tienes una carpeta con archivos .md, ejecutas el programa y te genera un sitio web completo con navegación, búsqueda, tablas de contenidos automáticas.

Funciona bien para documentación, wikis personales, apuntes de clase, manual de usuario. Algo que empezó como un cuaderno de notas en Markdown se convierte en una página web decente.

El Markdown se transforma tal cual. Las rutas entre archivos se resuelven solas. Si en tus apuntes enlazas a otro archivo, el generador crea los enlaces correctamente en el HTML.

Se instala por terminal. Luego le dices la carpeta de origen, la carpeta de destino, y listo. Genera toda la web estática sin necesidad de base de datos ni servidor complejo. Subes los archivos HTML a cualquier hosting y funcionan.

Puedes personalizar el CSS y la estructura básica. El tema por defecto es limpio y legible en cualquier dispositivo. Si quieres cambiar colores o la distribución, tienes los archivos de plantilla.

Cuando tus apuntes crecen, la búsqueda indexa automáticamente todo. Tienes un buscador en la página para encontrar una palabra clave en todos los documentos.

He probado con wikis de miles de páginas. El tiempo de generación es rápido, en cuestión de segundos incluso con bastante contenido.

Un problema que hay es con las imágenes. Si las referencias están mal en el Markdown, las rutas en el HTML también te quedan mal. Tienes que asegurarte de que tus imágenes están en los directorios correctos.

Lo mejor es que si necesitas cambiar algo en tus apuntes, editas el Markdown y regeneras. No tienes que tocar HTML nunca. Mantenerlo es cosa de minutos.
